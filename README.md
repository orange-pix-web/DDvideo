# 拼多多商品素材批量打包助手

独立 Chrome Manifest V3 扩展。支持从 TXT、CSV、XLSX 导入拼多多商品链接，逐个解析并按商品 ID 生成 ZIP。

## 功能

- 主图、SKU图、详情图、SKU文字、视频可分别勾选。
- ZIP 内所有文件平铺，不建立子文件夹。
- 主图：`商品ID_主图01.jpg`。
- SKU图：`商品ID_SKU01_SKU文案.jpg`。
- 详情图：`商品ID_详情图01.jpg`。
- SKU文字：`商品ID_SKU文字.txt`。
- 视频：`商品ID_视频01.mp4`。
- 批次完成后可生成 UTF-8 BOM 编码的 `SKU汇总.csv`。
- 导入时自动去除完全相同的商品链接。
- 可调整商品之间的等待时间（默认 8 秒）和 SKU 切换间隔（默认 800 毫秒）。
- 检测到安全验证或操作频繁提示时自动暂停，人工验证后可继续。
- 失败、跳过和待验证任务可一键重新加入队列。
- 已有解析结果可在任务列表中手动重新打包，无需再次打开商品页。
- 可以随时导出当前已解析记录的 SKU 汇总 CSV。
- SKU严格按页面规格组合逐条保留，不按文案或图片地址去重；共用图片的SKU也会分别生成文件。
- 解析过程不会自动向下滚动，避免进入页面底部的无限推荐商品流。
- SKU弹窗未显示时仍会读取隐藏规格DOM；没有规格按钮的单规格商品会生成“默认规格”记录。

## 安装

1. Chrome 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择目录 `D:\ZC\DDvideo`。
5. 点击扩展图标打开任务管理页。

## 使用

1. 导入含 `yangkeduo.com` 商品链接的 TXT、CSV 或 XLSX。
2. 勾选需要下载的内容。
3. 点击“开始任务”。
4. 不要关闭扩展创建的拼多多后台任务标签页。

SKU价格通过页面规格面板逐项选择后读取。拼多多页面结构或风控发生变化时，失败原因会记录在任务列表中。
